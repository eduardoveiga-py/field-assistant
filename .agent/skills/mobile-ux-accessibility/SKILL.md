# Skill: Interface Mobile e Acessibilidade

## Diretrizes
1. O aplicativo é projetado para uso com uma mão no iPhone XR e tela ampla no iPad / Web.
2. Tamanho mínimo de alvo de toque: 48x48 dp.
3. Alto contraste para legibilidade sob luz solar externa.
4. Fluxo rápido de registro de revisita: menos de 5 toques para salvar notas e próximo passo.
5. Suporte a Dynamic Type (font scaling) e Semantics para leitores de tela.
